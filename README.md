# The Depths
A top down 2D game I created for a game jam. Find all the bottles in the map while avoiding enemies and currents!

<img src="https://github.com/user-attachments/assets/cd0217f1-3a87-4cc5-ac3e-937b47c5d047" alt="drawing" width="500"/>






# How to play
- WASD to move


# Tips
- This game is intentionally tedious and difficult. If you are lost, try to find the red light!
- Collecting bottles spawns in enemies and currents, so be careful!
